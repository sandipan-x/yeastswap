# YeastSwap

Convert yeast between fresh, active dry and instant with our free yeast conversion chart. Includes a flour-weight recipe scaler and proofing time tips.

## Features
- Three-way converter: fresh ↔ active dry ↔ instant with all results shown at once
- Recipe scaler by flour weight with baker-friendly yeast percentages
- Proofing time tips by dough temperature with visual readiness cues
